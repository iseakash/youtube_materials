# Docker & AI — Project Playground

> From containerizing apps to deploying AI services — Docker skills every AI Engineer needs.

This repo is a growing collection of hands-on Docker projects. Each project builds a real-world skill you'll use when shipping models, serving APIs, or orchestrating multi-service AI pipelines.

## Projects

### Foundation — Docker Essentials

| # | Project | Stack | What You'll Learn |
|---|---------|-------|-------------------|
| 1 | **Docker Volume Demo** | Flask + MySQL | Named volumes, data persistence, why containers lose data |
| 2 | **Dockerize Personal Portfolio** | Nginx + Node.js + FastAPI | Reverse proxy, health checks, 3-tier orchestration |
| 3 | **Multi-Container Employee Management** | Nginx + Next.js + FastAPI + PostgreSQL | Full CRUD, custom networks, env config, CORS |

### Applied AI *(coming next)*

Projects for serving ML models, inference pipelines, vector DBs, and agent backends — all containerized.

## Quick Start

```bash
cd Docker/<project-folder>
docker compose up --build
```

Each project is self-contained with its own README, Dockerfiles, and `docker-compose.yml`. No prior Docker knowledge required — jump in at any level.
